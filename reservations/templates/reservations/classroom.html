Migraciones: cambios de base de datos con control

Proyecto de reservas para practicar la evolución segura de un esquema.

4. ¿Qué es una migración?

Una migración es un archivo versionado que describe cómo transformar el esquema de datos de un estado a otro. Django registra las aplicadas en django_migrations.

Resuelve el SQL manual, la falta de trazabilidad y la desincronización entre desarrollo, pruebas y producción.

4.2 Crear y aplicar cambios

python manage.py makemigrations reservations
python manage.py migrate
python manage.py showmigrations
python manage.py sqlmigrate reservations 0003

makemigrations detecta cambios de modelos y genera archivos: no modifica la base. migrate aplica migraciones existentes y pendientes.

Evolución incluida

0001
Reserva inicial
0002
Email, estado y cantidad
0003
Renombre, choices e índice
0004
Fecha de edición, restricción e índice

Revertir y verificar

python manage.py migrate reservations 0002
python manage.py migrate reservations zero

Versiona migrations/ junto a cada cambio de modelo. Consulta la API o el admin.
